# 📊 Sales Performance Dashboard – Power BI

## 📌 Project Overview

This project is a **Simple Sales Performance Dashboard** created using **Microsoft Power BI**.

The objective of this project is to transform sales data into an interactive dashboard that helps users understand sales performance across **years, regions, and months**.

This dashboard was created as part of **Day 3 – Dashboard Design Task**.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall sales performance.
- Compare sales across different regions.
- Analyze monthly sales trends.
- Provide important KPIs such as Total Sales and Total Profit.
- Create an interactive dashboard using Power BI.
- Allow users to filter the dashboard using slicers.

## 📊 Dashboard Components

### 1. KPI Cards

The dashboard contains important business KPIs such as:

- **Total Sales**
- **Total Profit**
- **Total Orders**
- **Customer Count / Quantity**

These KPIs provide a quick overview of overall business performance.

### 2. Sales by Year

A column/bar chart is used to compare total sales across different years.

This helps identify whether sales are increasing or decreasing over time.

### 3. Sales by Region

A chart is used to compare sales across different regions:

- Central
- East
- South
- West

This helps identify which region contributes the most to total sales.

### 4. Sales by Month

A line chart is used to analyze the monthly sales trend.

This helps identify:

- High-sales months
- Low-sales months
- Overall sales trends throughout the year

### 5. Interactive Slicers

The dashboard includes slicers that allow users to filter the data interactively.

Available filters include:

- **Region**
- **Month**

When a slicer is selected, the dashboard visuals update automatically.

---

## 📈 Key Insights

The dashboard can be used to answer questions such as:

- What is the total sales amount?
- What is the total profit?
- Which region has the highest sales?
- Which months have the highest sales?
- How are sales changing over the years?
- How does filtering by region or month affect overall performance?
